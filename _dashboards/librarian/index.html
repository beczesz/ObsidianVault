Operation Modes Reference Librarian v0.6 — 6 modes
index
Reads a scope, generates 5 index files (INDEX, KNOWLEDGE_MAP, DECISIONS_INDEX, OPEN_QUESTIONS, GAPS). Rare — weekly or monthly.
/lib-index
retrieve
Context-protection mode. Reads vault on behalf of caller — returns filtered summary. Two-tier algorithm: tier-1 for global queries, tier-2 for unit-specific.
/lib-find
tidy
Housekeeping — orphan files, broken links, byte-identical duplicates. Dry-run default. Logs every action with undo commands.
/lib-tidy
audit
Vault health report — stale files, missing frontmatter, structure anomalies, agent meta-index maintenance. Monthly cadence.
/lib-audit
integrate
Surveys external folders (Downloads, Desktop, Documents) and proposes vault-integration for relevant files. Never moves anything autonomously.
/lib-integrate
deep-clean
Deep cleanup — byte-identical duplicates, empty files, temp files, stale-status archives. Cross-reference check before every move/delete. Dry-run default.
