How the system improves itself
1 Agent runs learn/reflect → drops a proposal → 2 Human reviews via /<agent>-learning-accept → 3 Active: loaded into the agent's next prompt → 4 Unused 4 weeks or contradicted → retired

The loop is deliberately human-gated (BDOS principle: agents never mutate their own prompts autonomously). To make proposal-generation continuous, schedule each agent's reflect / Alfred curate mode (weekly) so new candidates accumulate here automatically; acceptance stays a one-click human decision.
