7 Modes Reference Curator v0.3
survey
Scans the family, (re)generates 00_DASHBOARD_INDEX.md. Context-protected — read-only, only writes the index.
/dash-survey
build
Scaffolds a new dashboard per the build recipe — DESIGN_SYSTEM tokens, parsers, sync loop, launcher registration, index update. Starts at v0.1.0.
/dash-build
tend
Restores or extends an existing dashboard — new widget, new data source, bug-fix, standard alignment. Version bump + audit trail required.
/dash-tend
retire
Archives or deletes a dashboard — launcher deregistration, index update. Destructive — dry-run default, confirmation required.
/dash-retire
audit
Checks the whole family against the 7 laws and DESIGN_SYSTEM — drift matrix, version mismatches, legacy list. Detect only, no fixes.
/dash-audit
serve
Controls the local gallery server on port 4321 — start, open a dashboard in browser, check status, stop. Never kills a foreign process.
/dash-serve
promote
Codifies a learned pattern into DESIGN_SYSTEM.md, then rolls it out family-wide with version bumps. Dry-run default, confirmation gate before family-wide execution.
/dash-promote
