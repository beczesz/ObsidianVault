7 Modes Reference Curator v0.3 #5
survey
Scans the family, (re)generates 00_DASHBOARD_INDEX.md. Context-protected — read-only, only writes the index.
/dash-survey
build
Scaffolds a new dashboard per the build recipe — DESIGN_SYSTEM tokens, parsers, sync loop, launcher registration, index update. Starts at v0.1.0.
/dash-build
tend
Restores or extends an existing dashboard — new widget, new data source, bug-fix, standard alignment. Version bump + audit trail required.
/dash-tend
retire
Archives or deletes a dashboard — launcher deregistration, index update. Destructive — dry-run default, confirmation required.
/dash-retire
audit
Checks the whole family against the 7 laws and DESIGN_SYSTEM — drift matrix, version mismatches, legacy list. Detect only, no fixes.
/dash-audit
serve
Controls the local gallery server on port 4321 — start, open a dashboard in browser, check status, stop. Never kills a foreign process.
/dash-serve
promote
Codifies a learned pattern into DESIGN_SYSTEM.md, then rolls it out family-wide with version bumps. Dry-run default, confirmation gate before family-wide execution.
/dash-promote

Server API Reference dash-server.mjs · port 4321 #12

Every route exposed by _dashboards/_tools/dash-server.mjs. Green badge = read-only, amber badge = writes to vault files. Path-lock and body-size guards noted per endpoint.

ANYread-only
/
Redirects (internal rewrite) to /_dashboards/index.html. Entry point for the launcher when the server is opened bare.
Response
200 text/html — launcher HTML
GETread-only
/* (catch-all static)
Serves any file from the vault root. Dashboards use this to fetch markdown sources (e.g. /02_Areas/.../Pipeline.md). Directories auto-resolve to index.html.
Response
200 + MIME-typed body · 404 text/plain on missing · 403 on path-traversal attempt
Security
Path locked to VAULT_ROOT via safeResolve() — any ../ traversal returns 403. Cache-Control: no-store.
SSEread-only
/__events
Server-Sent Events stream. Dashboards subscribe here for sub-second push notifications when watched markdown files change. The server watches 02_Areas/Sonrisa/CPS and 02_Areas/Navigátor Podcast by default (override via WATCH_DIRS env var).
Event name
change
Event data (JSON)
{ files: string[], ts: number } — array of changed filenames + epoch ms timestamp
Keep-alive
SSE comment ping every 25s. retry: 3000ms hint sent on connect.
Debounce
150ms — rapid successive changes are collapsed into one broadcast. Only *.md files trigger an event.
GETread-only
/api/search
FTS5 full-text vault search. Spawns query.py from the vault-indexing capability and returns ranked results from the SQLite cache.
Query params
q (required) — search string
limit (optional, default 20, max 100)
Response 200
[{ path, title, description, category, area, rank }]
Errors
400 if q is empty · 500 if query.py exits non-zero or JSON parse fails
Security: q passed as argv element — no shell interpolation. CORS: Access-Control-Allow-Origin: *.
POSTwrite
/_signals/approval
Approval signal endpoint for Presto publication workflow. Writes a signal file to Presto's inbox so the agent can pick it up during its next sync run. Also broadcasts a change SSE event after writing.
Request body (JSON, max 4 KB)
{ publication_id: string, action: "approve"|"reject", project?: string, campaign_id?: string, channel?: string }
Response 201
{ ok: true, file: string } — filename of the written signal
File written
00_Prompts/BDOS/agents/presto/_inbox/approval-actions/<ts>_<publication_id>.md
Path-locked to Presto inbox only. Body capped at 4 096 bytes (connection destroyed on overflow).
POSTwrite
/api/alfred/capture
Append-only capture endpoint for Alfred. Writes a single timestamped bullet line under the ## Unprocessed section of Alfred's inbox. Creates the section if missing. Triage and routing happen when Alfred runs sync mode later. Also broadcasts a change SSE event after writing.
Request body (JSON, max 8 KB)
{ text: string } — the capture text (required, non-empty)
Response 201
{ ok: true, ts: "YYYY-MM-DD HH:MM", preview: string }
File written
02_Areas/Personal Growth/Alfred/inbox.md
Line format appended
- [YYYY-MM-DD HH:MM] <text>
Path-locked to inbox.md only — pure Node fs, no shell. Body capped at 8 192 bytes. CORS: Access-Control-Allow-Origin: *.
POSTRW
/api/alfred/process
Alfred inbox sor Haiku 4.5-tel taskká parse-olva: scope, title, due, priority, tags kinyerése, majd formázott checkbox task sor írása todos/<scope>.md ## Active szekciójába. Érvényes scope-ok: personal, family, fokuszpont (ismeretlen scope esetén personal). Magyar és angol relatív dátumok feloldva (holnap, jövő hétfő). Fallback: ha nincs API kulcs, API hiba vagy parse sikertelen, a nyers szöveget inbox.md-be fűzi (capture-only), az input sosem veszik el. Broadcasts change SSE event after writing.
Request body (JSON, max 8 KB)
{ text: string } — the raw note text (required, non-empty)
Response 201 (mode: process)
{ ok: true, mode: "process", scope, task: { title, due, priority, tags }, line }
Response 201 (mode: capture-fallback)
{ ok: true, mode: "capture-fallback", scope: "personal", task: null, line }
Files written
todos/<scope>.md (process) · inbox.md (fallback)
Model: claude-haiku-4-5. Path-locked to Alfred todos/ and inbox.md only. Body capped at 8 192 bytes. CORS: Access-Control-Allow-Origin: *.
