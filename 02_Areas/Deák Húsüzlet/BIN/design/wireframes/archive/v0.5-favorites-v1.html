Rendezési logika

1
User rákattint a csillagra → item_id bekerül a user_favorites[] tömbbe (Frappe user doctype vagy localStorage fallback).
2
A terméklistát rendereléskor két csoportra bontjuk:
① Kedvencek (arany csillag, sárgás kártya)
② Többi termék (alapállapot)
3
A kedvencek a lista tetején jelennek meg, kategóriaszűrőn belül is elsők maradnak.
4
Ha egy kategóriában nincs kedvenc → a "Kedvencek" szekció el van rejtve, csak az "Összes termék" látszik.
5
Perzisztálás: Bejelentkezett usernél szerver oldal (user doctype). Nem bejelentkezett vendégnél localStorage, de vendég nem tud kedvencet menteni (login gate).
-- Frappe User Doctype extension
field: favorite_items
type: JSON Array
["item-001", "item-007", ...]

-- API endpoint
POST /api/favorites/toggle
{ item_id, user_id }
→ returns { is_fav: true|false }
