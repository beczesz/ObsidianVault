Rendezési logika

1
User megnyomja a csillag gombot → termék ID bekerül a user.favorite_items[] listába.
2
A terméklistát két csoportra bontjuk:
① Kedvenceim — arany csillag, sárgás keret
② Összes termék — normál állapot
3
Ha nincs kedvenc → a "Kedvenceim" szekció rejtve marad, tiszta lista jelenik meg.
4
Kategóriaszűrőn belül is működik: ha az adott kategóriában van kedvenc, ott is elöl jelenik meg.
5
Perzisztálás: bejelentkezett usernél szerver (Frappe user doctype). Vendégnél login nudge toast.

Hogyan működik

→
Kattints bármelyik csillag gombra a telefonon — a termék azonnal átmozdul a "Kedvenceim" szekcióba és arany lesz a csillag.
→
Ha újra kattintasz — eltávolítja a kedvencekből, visszakerül az "Összes termék" listába.
→
Ha nincs kedvenc → a "Kedvenceim" szekció automatikusan eltűnik.
Ez a valós UX viselkedés: az átrendezés azonnal történik, animáció nélkül (v0.5-ben). Animáció v1.0-ban jön.

CSS spec

↳
Pozíció: position:absolute; top:7px; right:7px;
A termékképen belül, mindig jobb felső sarok.
↳
Méret: 28×28px, border-radius:50% (kör)
Háttér: rgba(0,0,0,0.20) — látható bármilyen képen
↳
Off: stroke rgba(255,255,255,0.82), fill none
On: fill + stroke #F0A500
↳
Kedvenc kártya: border 2px solid #E8C84A, background #FFF8E1

Implementáció (Frappe)

↳
Tárolás: User doctype — favorite_items: JSON[]
Pl. ["item-001", "item-007"]
↳
API: POST /api/favorites/toggle
Body: { item_id, user_id }
Response: { is_fav: true|false }
↳
Vendég user: csillag tap → login nudge toast.
Nincs localStorage — nem mentünk vendégnél.
