1
User Behavior
Nagyobb kosár, group order, reorder — a felhasználó viselkedése indítja a loop-ot
2
System Efficiency ⚠
Jobb batching, kevesebb waste, optimalizált route — a rendszer hatékonysága nő
3
Savings Generation
Efficiency gain → savings pool keletkezik, amit el lehet osztani
4
Savings Distribution
Threshold discount, bundle pricing, recap — a user megkapja a megtakarítást
5
Feedback
"Eddig X lejt spóroltál", "next threshold Y lejnél" — a user látja az értéket
6
Behavior Change
User: nagyobb kosár, visszatérés, reorder → loop bezárul, újraindul
