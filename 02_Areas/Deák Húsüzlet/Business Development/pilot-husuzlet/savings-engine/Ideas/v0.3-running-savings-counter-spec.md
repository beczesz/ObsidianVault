# Running Savings Counter — Feature Spec v0.3

## 1. Problem Statement

A jelenlegi DH kosár egy egyszerű összegző: termékek + mennyiségek = becsült összeg. A vásárló nem kap visszajelzést arról, hogy a rendelése mennyire "jó döntés." Nem tudja, hogy egy kis változtatással elérheti az ingyenes szállítást vagy a 2% kedvezményt.

A DH core definíciója: **döntéstámogató rendszer, amely jobb döntéseket segít hozni.** A savings counter ezt teszi láthatóvá — minden kosárműveletnél valós időben.

## 2. Savings Modell — Single Source of Truth

### Két savings komponens (v0.3):

| Threshold | Feltétel | Saving | Típus |
|-----------|----------|--------|-------|
| Ingyenes szállítás | Kosár ≥ 150 RON | +10 RON (szállítási díj elengedve) | Fix |
| Mennyiségi kedvezmény | Kosár ≥ 300 RON | 2% a TELJES kosárértékből | Dinamikus |

### Számítási példák:

| Kosár | Szállítás saving | 2% kedvezmény | Összes saving |
|-------|-----------------|---------------|---------------|
| 120 RON | 0 | 0 | 0 RON |
| 180 RON | +10 RON | 0 | +10 RON |
| 350 RON | +10 RON | +7 RON | +17 RON |
| 500 RON | +10 RON | +10 RON | +20 RON |

### Backend adatmodell:
```
order.savings = {
  savings_total: 17,          // RON
  delivery_saving: 10,        // fix: 0 vagy 10
  volume_discount: 7,         // 2% * order_total (ha ≥300)
  volume_discount_pct: 2,     // %
  threshold_delivery: 150,    // RON
  threshold_volume: 300       // RON
}
```

Egyszer számolódik (rendelés lezárásakor), és **minden UI felület UGYANEZT olvassa.**

## 3. Goals

| # | Cél | Mérés |
|---|-----|-------|
| G1 | AOV (átlagos kosárérték) növelése | AOV ≥150 RON (jelenleg ~95 RON) |
| G2 | A vásárló érezze, hogy "okosabban vásárolt" | Post-order survey: ≥60% "igen" |
| G3 | Threshold achievement rate ≥30% | Hányan érik el a 150 RON-t |
| G4 | Kosár elhagyási arány nem nő | Checkout idő nem változik |

## 5. User Stories

**US-1:** Mint vásárló, a kosár képernyőn látni akarom, hogy hol állok a threshold-okhoz képest, hogy tudjam, érdemes-e még valamit hozzáadni.

**US-2:** Mint vásárló, amikor közel vagyok egy threshold-hoz, szeretném ha a rendszer felhívná a figyelmem.

**US-3:** Mint vásárló, a rendelés leadása után látni akarom, mennyit spóroltam.

**US-4:** Mint vásárló, a Rendeléseim listán is látni akarom a savings badge-et (perzisztens visszajelzés).

## 6. Requirements

### P0 — Must Have

#### R1: Progress bar a kosár képernyőn

Vizuális progress bar a kosár értékével a threshold-okhoz képest.

**Threshold szintek a progress baron:**
| Szint | Összeg | Jutalom | UI |
|-------|--------|---------|-----|
| ~~Minimum~~ | 80 RON | Rendelés leadható | ❌ NEM jelenik meg (technikai minimum) |
| Szállítás | 150 RON | Ingyenes szállítás (+10 RON) | 🔴 DOMINÁNS jelölő |
| Optimális | 300 RON | 2% kedvezmény | Halványabb jelölő |

**Acceptance criteria:**
- [ ] Progress bar mutatja a 2 threshold-ot (150 + 300)
- [ ] Aktuális összeg pozíciója valós idejű
- [ ] Ha egy szint elérve: checkmark + animáció
- [ ] Üres kosárnál: progress bar megjelenik 0-ról, szöveg: "Adj hozzá termékeket → 150 RON-tól ingyenes szállítás!"

#### R2: Decision Confidence — 3 sáv

Vizuális állapotjelző + nudge szöveg a kosár összeg alapján:

| Sáv | Kosárérték | Szín | Badge | Nudge szöveg |
|-----|-----------|------|-------|-------------|
| Alap | 0–149 RON | — (nincs badge) | — | "Még X RON → ingyenes szállítás" |
| Jó döntés | 150–299 RON | 🟢 Zöld | "Jó döntés — ingyenes szállítás!" | "Még X RON → 2% kedvezmény" |
| Optimális | 300+ RON | 🟢🟢 Sötétzöld/arany | "Optimális rendelés!" | — (nincs nudge, elérte a max-ot) |

**Nudge hangnem:** segítő, nem nyomó. Near zónában (140-150 RON) erősebb: "Már csak X RON → megéri!"

**Acceptance criteria:**
- [ ] 3 vizuális állapot a 2 threshold-hoz kötve
- [ ] Szín + szöveg dinamikusan változik
- [ ] Nem zavaró — kis badge, nem nagy banner
- [ ] A nudge szöveg nyelve HU/RO

#### R3: Savings breakdown

A progress bar alatt 1 soros breakdown:

- 150 alatt: nincs breakdown
- 150–299: "+10 RON megtakarítás (ingyenes szállítás)"
- 300+: "+10 RON szállítás + X RON kedvezmény (2%) = +Y RON"

**Acceptance criteria:**
- [ ] 1 sorban, a progress bar alatt
- [ ] Pozitív framing: "+X RON"
- [ ] Trust-építő — a vásárló érti, MIBŐL áll a saving

#### R4: Savings megjelenítés minden rendelés nézeten

A savings info a rendelés inherens tulajdonsága:

**Ahol megjelenik:**
- Checkout köszönő oldal (recap — NEW-3)
- Rendeléseim lista → kis "+X RON" badge minden rendelésnél
- Rendelés részletező (vásárlói nézet)
- Rendelés kártya + részletező (mészáros nézet)
- Rendelés kártya + részletező (futár nézet)

**Acceptance criteria:**
- [ ] Ugyanaz az `order.savings` adat — nem külön logika per nézet
- [ ] Minimális vizuális footprint (badge, nem blokk)
- [ ] A Rendeléseim listán a savings badge perzisztens visszajelzés (email pótlás)

## 9. Architekturális megjegyzés — Basket Loader engine

A reorder (NEW-4), családi csomagok (NEW-5), és jövőbeli kedvencek (v0.4) mind a Basket Loader engine-t használják:
```
loadBasket(source: last_order | bundle | favorite)
```
Közös merge logika: üres kosár → betölt, nem üres → modal (Replace / Merge / Cancel).
