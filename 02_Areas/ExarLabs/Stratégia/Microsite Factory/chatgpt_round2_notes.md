## 🛠️ A) DISCOVERY ENGINE MVP — konkrét workflow

> *"Az MVP-t brutálisan egyszerűen kell kezdeni. Nem scraper platformot építeni. Nem AI crawler orchestrationt. Hanem: egy félig manuális enrichment pipeline-t."*

### A 5-step pipeline (holnap indítható)

#### 1. **Google Maps search**
- Query: `"fogászat Budapest"` (városonként)
- Export oszlopok: név, website, telefon, rating, review count

#### 2. **Wappalyzer / BuiltWith enrichment**
- WordPress? Wix? Egyedi?
- SSL aktív?
- Mobilbarát meta?
- Technológiai stack

#### 3. **Google PageSpeed API**
- Mobile score
- Desktop score
- CLS, LCP
- Performance bottleneck

#### 4. **Claude / Gemini visual classification**
- Screenshot input
- Outputok: modern? outdated? trust level? mobile UX? premium feel? booking visibility?

#### 5. **Manual review + lead scoring**
- **NEM full automation** — AI-assisted, human curated
- Ez a kulcs: a polish a "moat" része

### Lead Scoring rendszer (0-24 pont)

| Dimenzió | Skála |
|---|---|
| Visual outdatedness | 0-3 |
| Mobile usability | 0-3 |
| Premium positioning mismatch | 0-3 |
| Missing CTA / booking | 0-3 |
| SEO weakness | 0-3 |
| Brand inconsistency | 0-3 |
| Slow performance | 0-3 |
| Review-rating opportunity mismatch | 0-3 |

**Threshold: 18+ pont = hot lead.**

> *"Ez teljesen elég MVP-nek."*
