## Key Insights

### ChatGPT Strategist (importált 2026-05-16)
- **Stratégiai reframe:** "AI-leveraged local business transformation engine" — nem agency, nem SaaS, nem AI tool, új kategória.
- **Vertical cognition** (Dental Pack / Beauty Pack stb.) mint industry cognition layer = **valódi moat** (NEM template).
- **AI-assisted handcrafted outreach** — NE legyen tömeges spam, utolsó 10-15% emberi polish.
- **3-tier termékmodell:** Statikus / Integrált / Mini-app (booking = complexity boundary, NEM checkbox).
- **Composable architecture** preferált: Cal.com embed + Firebase + ConvertKit, NEM saját backend.
- **Microsite mint belépési pont:** transformation ladder microsite → CRM → automation → ERP.
- **"Hosting" framing kerülendő** — "digital presence maintenance", "online presence care" stb.

### Perplexity Researcher (importált 2026-05-16)
- **Magyar AI adopció 3,7%** vs 8% EU átlag → done-for-you híd-szerep.
- **Fogászat = 1. vertikum megerősítve**, dental tourism Budapest külön alszegmens (magasabb ASP).
- **GTM message:** "fogászati online jelenlét" > "AI weboldal".
- **Árazás:** €25-45/hó belépőszint magyar KKV-nak, működik IF standardizáció + add-on.
- **Vertikum sorrend korrigálva:** fogászat → szépségipar → **könyvelők** → ügyvédek (eredeti: → ügyvéd → könyvelő).
- **Validációs lépések javasolva:** 20 audit + 8-10 interjú + landing A/B teszt.

### Claude saját pre-validation
- **99% margin tévedés:** Szabolcs opportunity cost beszámítva ~60-65% reális gross margin.
- **Support burden:** 120 ügyfélnél ~80 óra/hó, NEM fedezi a €2k recurring.
- **Churn:** SaaS-szerű 5-10%/hó valószínű, havi 6-12 új ügyfél kell csak fenntartásra.
- **Moat hierarchia:** Industry Cognition Layer (erős) > Portfolio flywheel (erős) > Tech stack (gyenge).

### Gemini Validator (importált 2026-05-16)
- **GDPR/Grt blokk:** Unsolicited demo Magyarországon B2B-ben sem mehet előzetes hozzájárulás nélkül → **soft consent funnel kell** (LinkedIn / event / partner).
- **€25/hó margin-illúzió:** 1.5h/hó support/ügyfél → €16/óra effektív → "alulfizetett support ügynökség".
- **Lock-in visszafelé sül el:** SMB-felé fenyegetés, nem előny. "Fogjuk a kezed örökre" framing kell.
- **Skálázhatóság-csapda:** 5 új/hó @ 5% konv = 100 demó × 2h = 200 óra/hó → burnout 4. hónapban.
- **Industry Cognition Layer = buzzword:** egy system prompttal replikálható, NEM moat.
- **Sub-brand reputációs kannibalizmus:** ExarLabs név sérül → külön brand kötelező.
- **AAM/ÁFA átlépés:** ~50 ügyfélnél (€60k/év > 12M HUF) → 27% ÁFA → €30/hó kezdőár kell.
- **TOP 3 Silent Killer:** (1) Konverziós illúzió 0.5% nem 5%; (2) Integrációs szakadék pácienskezelőkkel; (3) Sub-brand kannibalizmus.

### Csapat-konszenzus (BMC v0.3 alapja)
- Megerősített: fogászat mint első vertikum, transformation ladder long-term, composable architecture, dental tourism alszegmens
- Felülbírált: unsolicited demo → soft consent, ExarLabs sub-brand → külön brand, 120 → 60-80 ügyfél, 99% → ~55-65% margin, Industry Cognition Layer → portfolio+integráció+sticky funkció
- Új stratégiai prioritás: pácienskezelő szoftver (FlexiDental, Dentasoft) integráció
