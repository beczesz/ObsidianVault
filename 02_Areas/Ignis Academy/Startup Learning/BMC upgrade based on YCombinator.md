Below is a **formal, comprehensive improvement plan** for **BMC v2.1**, structured along the nine building blocks of the Business Model Canvas and reflecting what a **Series A investor, an accelerator, or an EU evaluator** would expect from a top-tier enterprise SaaS BMC.

The goal is to evolve v2.1 from **8.8/10** to a **9.5–10/10 investor-ready document**.

---

# 1. VALUE PROPOSITION — Improvements

### **1.1. Make the “pain → claim → gain” structure explicit**

Right now the value prop is strong, but it is descriptive.  
Investors prefer a sharp sequence:

- **Pain:**  
    Low L&D ROI, fragmented learning, skill gaps, compliance risks, inefficient onboarding.
    
- **Claim:**  
    AI-driven skills intelligence engine + personalized micro-learning + organizational skills graph.
    
- **Gain:**  
    Measurable competence development, reduced training waste, improved performance.
    

Add a **one-page “Before / After” transformation map** (buyers love these).

### **1.2. Strengthen quantification**

Add concrete %/time/cost improvements:

- “Reduce onboarding time by 30–50%.”
    
- “Increase completion rates by 2–3× versus static e-learning.”
    
- “Reduce redundant training hours by 40–60%.”
    
- “Predict skill gaps 3–6 months earlier.”
    

These make the value proposition more credible.

### **1.3. Add competitor differentiation table**

Brief, but essential:

|Competitor|Weakness|Ignis Advantage|
|---|---|---|
|Udemy Business|No personalization|AI Skills Engine|
|Coursera for Business|Academic but slow|Micro-learning for enterprise|
|LinkedIn Learning|Breadth but shallow|Skills intelligence + dashboards|

# 2. CUSTOMER SEGMENTS — Improvements

### **2.1. Add TAM–SAM–SOM model**

This is expected by investors:

- **TAM (Global L&D market)**
    
- **SAM (Corporate future-skills training)**
    
- **SOM (Target market in Romania + EU first)**
    

A simple chart is enough.

### **2.2. Add HR procurement triggers**

Map what triggers the purchase:

- New leadership programs
    
- Annual performance review cycles
    
- Compliance requirements
    
- Digital transformation initiatives
    
- Onboarding waves (mergers, new departments)
    

This helps refine sales strategy.

---

# 3. CHANNELS — Improvements

### **3.1. Add Cost of Acquisition (CAC) expectation**

Channels should connect to CAC efficiency:

- Outbound CAC: Medium-high
    
- Content marketing CAC: Low
    
- Partner channel CAC: Low-medium
    
- Events CAC: High but strategic
    

This makes the channel strategy more financially meaningful.

### **3.2. Add Partner Channel Strategy**

Right now partners are listed but not operationalized.  
Add:

- Commission model
    
- Co-sale workflows
    
- Integration bundle pricing
    
- Onboarding kits for partners
    

---

# 4. CUSTOMER RELATIONSHIPS — Improvements

### **4.1. Add Customer Journey Map**

Currently it is descriptive.  
Add a **visual 5-stage enterprise journey**:

1. Discovery
    
2. Evaluation
    
3. Pilot
    
4. Rollout
    
5. Expansion (new departments + analytics add-ons)
    

### **4.2. Add measurable success KPIs**

Each stakeholder should have KPIs:

- **Economic Buyer:** ROI, adoption %, training hours saved
    
- **Champion:** completion rate, implementation time
    
- **Admin:** support tickets, provisioning automation
    
- **Learner:** learning frequency, competency improvement
    
- **Executive:** dashboard insights, department-level growth
    

This aligns with CSM excellence.

---

# 5. REVENUE STREAMS — Improvements

### **5.1. Add Tiered Pricing Examples**

Make pricing tangible:

- **Core**: €3–€5 per user per month
    
- **Professional**: €6–€9
    
- **Enterprise**: €12–€15
    
- **Analytics Add-On**: +€2–€4
    
- **White label**: €3,000 setup + €1,000 yearly
    
- **Integrations**: €1,500 setup + €500 yearly
    

This prepares you for procurement.

### **5.2. Add “Expansion Revenue” concept**

Investors want:

- **Net Revenue Retention (NRR)**
    
- Upgrades on:
    
    - More seats
        
    - More departments
        
    - More analytics modules
        
    - Certifications
        
    - Workshops

# 6. KEY RESOURCES — Improvements

### **6.1. Add IP Strategy**

Important for EU grants and investors:

- Trademark Ignis Academy
    
- Patentability assessment of Dynamic Student Profiling
    
- Internal content IP ownership
    
- Unique training data accumulation as differentiator
    

### **6.2. Add hiring roadmap**

Show when and how the team scales:

- AI engineer
    
- CSM manager
    
- Enterprise account manager
    
- Content designer
    
- DevOps engineer
    

Investors want to see progression.

---

# 7. KEY ACTIVITIES — Improvements

### **7.1. Add innovation roadmap tied to TRL**

Map Key Activities to TRL 3–7:

- TRL 3–4: AI prototypes
    
- TRL 5: Pilot deployments
    
- TRL 6: Validated systems in business clients
    
- TRL 7: Scaled rollouts with full analytics
    

This aligns with grant scoring and shows maturity.

### **7.2. Add quarterly milestones**

Each quarter should have:

- Feature sets
    
- Customer acquisition metrics
    
- Release roadmap
    

---

# 8. KEY PARTNERS — Improvements

### **8.1. Add partner incentive model**

Define:

- Referrals: 10–20% of first-year ARR
    
- Integration partners: 15–25%
    
- Training firms: co-branded offers with 50/50 revenue share
    

### **8.2. Add “non-negotiable partner criteria”**

Professionalize the ecosystem:

- ISO compliance
    
- GDPR readiness
    
- Technical onboarding capability
    
- Sector expertise (HR, L&D, training)
    

---

# 9. COST STRUCTURE — Improvements

### **9.1. Add CAC and LTV formulas**

Investors expect:

- CAC target
    
- LTV/CAC ratio: should be >3
    
- Payback period <12 months
    

### **9.2. Add margin model**

Break into:

- Gross Margin
    
- Contribution Margin
    
- Operating Margin
    

This is essential for SaaS financial maturity.

---

# 10. OVERARCHING IMPROVEMENTS (Most Impactful)

### **10.1. Executive Summary (1 page)**

Your BMC is extremely detailed—excellent for internal use.  
But for external readers you need a **1-page, high-level overview**.

### **10.2. Competitive Landscape (1 page)**

Very simple but powerful:

- Feature comparison
    
- Pricing comparison
    
- Positioning map (“AI Skills Intelligence” in top-right quadrant)
    

### **10.3. Go-to-Market Strategy (2 pages)**

Right now GTM is scattered across channels and relationships.

Create a dedicated GTM section:

- ICP definition
    
- Lead generation funnel
    
- Sales playbooks
    
- Pilot → conversion model
    

### **10.4. Risk Matrix**

Needed for EU proposals and investors:

- Technical risks
    
- Market risks
    
- Compliance risks
    
- Operational risks
    

Each paired with mitigation.
