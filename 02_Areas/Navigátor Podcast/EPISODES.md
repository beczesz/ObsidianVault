# Navigátor Podcast — Epizód Roster

> **Single source of truth** a podcast platform-státuszáról és metrikáiról. A
> [`navigator.html`](/_dashboards/navigator.html) dashboard ezt a frontmattert
> olvassa (`episodes` tömb), 8 másodpercenként / SSE push-ra frissül.
> **Edit ezt a fájlt Obsidianban, ne a HTML-t.**

## Mezők

| Mező | Jelentés |
|------|----------|
| `ep` | Epizódszám (1–42) |
| `guest` | Vendég neve |
| `topic` | Rövid téma |
| `duration` | Hossz (`H:MM:SS`) |
| `youtube_id` | YouTube videó ID |
| `youtube_date` | YouTube publikálás dátuma (= a HELYES Spotify dátum) |
| `spotify` | `ok` \| `date_fix` \| `missing` \| `unverified` |
| `spotify_current` | Jelenlegi (hibás) Spotify dátum |
| `spotify_correct` | Helyes dátum (= youtube_date) |
| `views` | YouTube nézettség (0 = nincs adat) |
| `cluster` | Tematikus klaszter |
| `synthesis` | A `Synthesis/Podcast/<…>.md` fájl neve kiterjesztés nélkül (drawer enrichment) |
| `priority` | Elsőbbségi (2026-05-20 dátumú Spotify epizódok) |
| `top` | TOP performer (10k+ nézés) |
