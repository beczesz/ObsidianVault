## End Screen konfiguráció sablon

Minden videónál:
1. **Element 1:** "Best for viewer" (YouTube automatikusan választ) — bal oldalra
2. **Element 2:** Tematikus ajánlás (lásd fenti táblázat) — jobb oldalra
3. **Element 3:** Subscribe gomb — középre alulra
4. **Időzítés:** Utolsó 20 másodperc

### YouTube Studio navigáció
1. Nyisd meg: `studio.youtube.com/video/[YT_ID]/editor`
2. Kattints "End screen" szekcióra
3. Válaszd "Add element" → Best for viewer / Specific video / Subscribe
4. Igazítsd az elemeket az utolsó 20 mp-re
5. Save
