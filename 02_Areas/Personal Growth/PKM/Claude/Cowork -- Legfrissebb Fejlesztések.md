# Cowork -- Legfrissebb Fejlesztések

> Utolsó frissítés: 2026-03-23

---

## 2026. február 24. -- Nagy bővítés

### 10 új plugin
Az eredeti 11 mellé 10 új plugin érkezett, főleg pénzügyi és HR területen. A teljes lista a [[Cowork Plugins -- Áttekintés]] fájlban.

### Vállalati (Enterprise) funkciók
- **Privát plugin marketplace:** Vállalatok saját belső plugin könyvtárat hozhatnak létre, amelyet adminok terjesztenek a csapatok között
- **Privát GitHub repó forrás:** Plugin forrásként saját privát GitHub repót is meg lehet adni
- **Cross-app workflow:** Claude már Excel és PowerPoint között is átviszi a kontextust -- például egy Excelből húzott adatból azonnal PPT-t generál

### Új connectorok (MCP)
Az alábbi külső szolgáltatások csatlakoztathatók:
- Google Workspace (Calendar, Drive, Gmail)
- DocuSign
- Apollo, Clay, Outreach (sales)
- Similarweb, MSCI, FactSet (adat/pénzügy)
- LegalZoom, Harvey (jogi)
- WordPress

## 2026. január 30. -- Első plugin csomag

Az Anthropic nyílt forráskódúvá tette a belső használatú 11 pluginját, elérhetők:
- Közvetlenül a Cowork appban
- A [claude.com/plugins](https://claude.com/plugins) oldalon
- GitHub-on: [anthropics/knowledge-work-plugins](https://github.com/anthropics/knowledge-work-plugins)

**Kulcsgondolat a pluginokról:** "Egyszerű, hordozható fájlrendszerek, amelyek a tieid" -- nem lock-in, saját tulajdon.
