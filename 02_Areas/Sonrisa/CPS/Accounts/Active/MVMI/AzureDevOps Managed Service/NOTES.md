## What Is This Engagement

Azure DevOps platform (Server & Services) L3 managed support for MVMI Zrt. The service covers bug fixing, platform operations consulting, and containerization advisory. Tickets are submitted via an online portal, processed within SLA during business hours.

## Scope (from tender)

- Azure DevOps platform operations support (availability during SLA hours)
- Bug triage, root cause analysis, and resolution at component level (pipeline, build, release, integrations)
- System admin support (OS, DB, web server, patch management, version updates)
- Key user support (online/phone)
- Developer support (Azure DevOps usage, best practices, code review sessions)
- Containerization technology consulting
- Platform operations consulting

## Package Details (Essential Support - customized)

- 20 hours/month built-in capacity (standard Essential is 40h, reduced based on expected ticket volume)
- 10% discount on pre-booked hours
- Overtime billed at separate hourly rate
- Ideal for 10-15 tickets/month
- Optional: expert/developer consulting at hourly/daily rate (to be quoted)
