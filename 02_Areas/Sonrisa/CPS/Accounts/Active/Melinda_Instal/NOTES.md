## What Is This Account

**Melinda Impex Instal SA** is a Romanian national importer and distributor of installation materials and sanitary objects, operating across ~90% of Romania. Beyond products, they offer complete packages with technical support, distribution (regular runs), consultancy, and bathroom design.

The project: build a **mobile application for installers** (HVAC technicians) who work with Melinda Instal. The app helps installers organize material procurement, issue price quotations to their clients, manage installation jobs, access Melinda's webshop, and participate in a loyalty-points program.

## The Product (mobile app — feature summary)

**Platform:** Android + iOS (web view apps, responsive UI), portrait only, min 320px. Admin interface in web browser. Languages: RO + HU (default from user's ERP profile, user-adjustable).

**Core features:**
1. **User management** — installer registration (phone + password), manual approval by Melinda, loyalty-class + shop/webshop-customer assignment at approval
2. **Customer management** — installers register their own customers (individuals or legal entities); legal entities auto-filled from **ANAF** (Romanian fiscal agency) by company reg number
3. **Installation job management** — auto-default job per customer, multiple jobs, cart-per-job, archive of closed jobs
4. **Product catalog + webshop** — ERP-synced products, categories, prices, loyalty points, promotions, cross-sell/upsell, intelligent search (key success factor)
5. **Cart + order management** — multi-cart, multi-shop/warehouse fulfillment, per-shop pricing + stock, loyalty-point application (max e.g. 80% of value), ERP invoicing sync (job = order in ERP)
6. **Payment + delivery** — card, pay-at-delivery, AVIZ (later payment for shop customers); pickup in store / collection point / Melinda fleet / Postis courier
7. **Price quotation** — generate PDF quotes (+ self-service fees, call-out fees), multi-language, share via WhatsApp / Messenger / Gmail
8. **Loyalty points** — achievable / pending / usable classification, validity periods, classes (Bronze/Silver/Gold/Platinum), ERP-tracked, app calculates earnable points
9. **Notifications** — WhatsApp + Push, event-driven (inventory reservation, AVIZ ready, loyalty granted, registration approval, expiring promotions, point-earning deadlines)

## Tech / Integrations

- **Backend + functionalities:** StoreFactory ecommerce solution
- **Frontend:** web view embedded apps (iOS + Android), responsive UI
- **ERP integration:** Melinda's ERP is the single source of truth (users, products, pricing, loyalty points/classes); periodic sync; API structure a joint effort with Melinda IT
- **ANAF integration:** Romanian fiscal agency for legal-entity customer data
