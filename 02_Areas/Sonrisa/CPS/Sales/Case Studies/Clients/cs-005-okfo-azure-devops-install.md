## The Situation

Az OKFŐ Szakellátásfejlesztési és Koordinációs Igazgatóságának informatikai produktív környezetében futó alkalmazásai fejlesztésének életciklus-támogató rendszere elavult -- nem felelt meg a kor elvárásainak. A meglévő eszközkészlet nélkül a fejlesztések többszörös időt vesznek igénybe, ami gazdaságilag hátrányos a szervezet számára. A megoldás közbeszerzési eljárás keretében valósult meg.

---

## The Problem

- Az alkalmazásfejlesztési életciklust támogató rendszer (ALM) elavult, nem skálázható
- Forráskód-kezelés és CI/CD folyamatok hiányoztak vagy nem voltak egységesek
- A fejlesztők és üzemeltetők nem rendelkeztek modern, integrált szoftverfejlesztési platformmal
- Állami intézményként a megoldásnak földi (on-premises) környezetben kellett futnia, megbízhatóan és gazdaságosan

---

## What We Did

- **Demo/PoC környezet kiépítése:** Azure DevOps Server Express alapú proof-of-concept, amelyen a kulcsfelhasználók és üzemeltetők megismerkedhettek a rendszerrel és a koncepcióval -- döntési alap a teszt/éles környezethez
- **Teszt környezet kialakítása:** Önállóan, függetlenül üzemelő tesztelési célú Azure DevOps Server környezet felépítése
- **Éles (produkciós) környezet kialakítása:** Napi ügymenet-támogatásra alkalmas, on-premises Azure DevOps Server környezet implementálása
- **Projektvezetés:** Teljes körű projektvezetési feladatok a bevezetés alatt
- **CI/CD és SDLC tanácsadás:** Forráskód kezelés (Git), CI/CD pipeline kialakítás, szoftverfejlesztési életciklus-módszertan bevezetése
- **2 éves tanácsadási szerződés:** Folyamatos konzultáció maximum havi 10 órában az Azure DevOps Server és az SDLC folyamatok területén

---

## The Result

| Metrika | Előtte | Utána | Időkeret |
|---------|--------|-------|----------|
| Fejlesztési életciklus platform | Elavult, nem egységes | Modern Azure DevOps Server, on-premises | Implementáció után |
| CI/CD folyamatok | Hiányzó vagy ad-hoc | Strukturált pipeline-ok, Git forráskód kezelés | Bevezetéstől |
| Fejlesztési sebesség | Többszörös idő (elavult eszközök) | Normalizált, modern toolchain | Bevezetéstől |
| Tanácsadási folytonosság | Nincs | 2 éves support, max 10h/hó | Szerződés teljes időtartama |
| Környezetek száma | 0 modern | 3 (demo, teszt, éles) | Projekt végére |

**Összefoglaló:** Az OKFŐ elavult ALM rendszerét leváltottuk egy modern, on-premises Azure DevOps Server platformra -- PoC-tól az éles környezetig, projektvezetéssel és 2 éves tanácsadással, közbeszerzési keretben megvalósítva.

## Why They Chose CPS Over Hiring

Állami intézményként az OKFŐ-nek nem volt lehetősége gyorsan új szakembert felvenni a közbeszerzési és HR folyamatok miatt.
