# CPS Reports

Vault-side reporting structure for monthly CPS activity data sourced from Sontime.

## Folder Layout

```
Reports/
  raw/              -- Raw Sontime xlsx exports (input files)
  MUB/              -- Monthly Update Briefs (markdown, generated by /cps-stats)
```

Processed xlsx outputs (`_base.xlsx`, `_tam.xlsx`) are uploaded to SharePoint and are NOT stored in the vault. See `references/sharepoint-urls.md` in the plugin for upload destinations.

## Workflow

1. Download monthly activity report from Sontime (SharePoint raports folder)
2. Copy to `raw/activityreport_YYYY_MM.xlsx`
3. Run `/cps-stats` to process it (Phase A: classify, Phase B: generate)
4. MUB markdown is saved here: `MUB/MUB_YYYY_MM.md`
5. Upload _base and _tam to SharePoint (manual, see plugin references)

## Available Commands

| Command | Purpose |
|---|---|
| `/cps-stats` | Process raw xlsx into _base.xlsx, _tam.xlsx, MUB |
| `/cps-tig` | Review contractor TIG and draft AM confirmation emails |

## File Naming

| Type | Convention |
|---|---|
| Raw input | `raw/activityreport_YYYY_MM.xlsx` |
| Monthly Update Brief | `MUB/MUB_YYYY_MM.md` |
