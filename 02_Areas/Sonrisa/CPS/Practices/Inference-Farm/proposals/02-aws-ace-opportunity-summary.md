### Solution Description (Short)

Self-hosted LLM inference platform enabling enterprises to run open-source AI models (Qwen-32B, DeepSeek, Llama) on dedicated AWS GPU infrastructure. Delivers secure, token-based access for coding assistance and productivity tasks with zero external data exposure.

### Solution Description (Long)

Sonrisa LLMaaS addresses enterprise demand for generative AI while solving critical concerns around data privacy, cost predictability, and vendor lock-in. Built entirely on AWS GPU infrastructure (G5 instances), the platform provides:

- **OpenAI-compatible API** for seamless integration with existing tools
- **Web interface** for non-technical users
- **Token-based billing** with predictable pricing (40-60% cheaper than public APIs)
- **EU data residency** with full GDPR compliance
- **Multi-model support** optimized for different use cases (coding, writing, analysis)

Target customers include mid-market and enterprise organizations with:

- Data sovereignty requirements (regulated industries, EU-based)
- High-volume AI usage (development teams, content operations)
- Cost sensitivity (reducing OpenAI/Azure spend)
