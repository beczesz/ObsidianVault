# Video Release Runbook — Vision Corner

Source: `Video Release Manual.docx` (uploaded 2026-05-07)
Use as a checklist when publishing a new episode.

---

## Phase 1 — File preparation

- [ ] **Rename the accepted cut** to: `EPXX Episode title without emoji.mp4`
  - Episode title comes from the post-production brief
  - No emoji in the filename
- [ ] **Move the file** to the `Final Cuts – PUBLIC` folder

## Phase 2 — Stream upload & metadata

- [ ] **Open the file** and set the title below the video player:
  - Format: `Episode title <EMOJI> Vision Corner EPXX`
- [ ] **Write the video description** (below the title box)
  - Easiest start: copy from a previous episode and adapt the short description
- [ ] **Update recommendation links** in the description
  - To grab a previous episode link: Share → Manage Access → Links → copy the link that is "accessible to anyone with a Sonrisa account, no edit/download"
- [ ] **Create the episode thumbnail** in Canva (template based on episode title):
  - https://www.canva.com/design/DAGeQvvJSZg/F9rShgUIG9OxzxEBT2fKGQ/edit
- [ ] **Configure video settings**
- [ ] **Upload the thumbnail** to Stream
- [ ] **Upload or generate the transcript**
- [ ] **Generate chapters** based on the transcript

## Phase 3 — Get the correct share link

- [ ] **Check Manage Access** for an existing no-download link; if missing, create one:
  - Share → Share → cogwheel icon next to "Copy link"
  - Configure the link
  - Apply & Copy link
- [ ] ⚠️ **Use THIS link for sharing** — other links cause access problems

## Phase 4 — Distribution surfaces

- [ ] **Add the episode to the Vision Corner playlist:**
  - https://sonrisakft.sharepoint.com/sites/content/Lists/Vision%20Corner/AllItems.aspx?newTargetListUrl=%2Fsites%2Fcontent%2FLists%2FVision%20Corner&viewpath=%2Fsites%2Fcontent%2FLists%2FVision%20Corner%2FAllItems%2Easpx&viewid=ad5b6596%2Da7a2%2D49fc%2Dab5e%2Da60bea13735a&playlistLayout=playback&itemId=6
- [ ] **Update the Vision Corner SharePoint page:**
  - https://sonrisakft.sharepoint.com/SitePages/VisionCorner.aspx
  - Duplicate a section matching the "one left, one right" flow
  - Move the new section to the top, then edit it
  - ⚠️ **Publish the changes** when done

## Phase 5 — Announcement email

- [ ] **Schedule the announcement email**
- [ ] **From:** `content@sonrisa.hu` (Claudia, Szabolcs, and Bence have send rights)
- [ ] **To:** `all@sonrisa.hu`
- [ ] **Subject:** episode title (with emojis, EP number, show name) — or a variation
- [ ] **Greeting:** `Hi everyone 👋`
- [ ] **Body, in order:**
  1. 2–3 sentences describing what's new in this episode
  2. Paste the share link from Phase 3 → produces a video embed (use web Outlook if it doesn't appear). Embed should be **as close to the top as possible**.
  3. After the embed: link to the question submission form
- [ ] **Sign-off:**
  ```
  Yours truly,
  the Content Team
  ```

## Gotchas (don't forget)

1. **Filename must NOT contain the emoji** — but the Stream title and email subject DO contain it.
2. **Use only the cogwheel-configured share link** — copying any other link will lead to access problems for viewers.
3. **The Vision Corner SharePoint page change isn't live until you click Publish.**
4. **Video embed in the email** — falls back to web Outlook if the desktop client doesn't render it. Embed must be near the top.
5. **The source manual contains 8 screenshots** I haven't transcribed — open the original docx if a step's UI is unclear.
