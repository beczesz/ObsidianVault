## Chapters

### Ch 1: What IS Copilot Studio?
- Positioning: Microsoft's no-code/low-code AI agent builder
- Where it fits in the Microsoft ecosystem
- What you can build with it
- Key differentiator vs generic chatbots

### Ch 2: Core Concepts – Topics, Triggers & Nodes
- Topics = conversation modules
- Trigger phrases (how the bot decides what to do)
- Node types: Message, Question, Condition, Action, End
- Conversation flow logic

### Ch 3: Generative AI – Knowledge Sources
- What "generative answers" means
- Connecting to SharePoint, websites, uploaded files
- How the bot uses RAG (retrieval augmented generation)
- Guardrails: staying on topic, avoiding hallucinations

### Ch 4: Actions – Connecting to the Real World
- What actions are (calling flows, APIs, connectors)
- Power Automate integration
- HTTP connectors
- When to use actions vs topics

### Ch 5: Channels – Where Your Copilot Lives
- Teams, website widget, SharePoint, WhatsApp, etc.
- Publishing process
- Multi-channel considerations

### Ch 6: Authentication & Security
- Anonymous vs authenticated bots
- Azure AD / Entra ID integration
- Data access and privacy considerations for SMBs

### Ch 7: Monitoring, Analytics & Improving Your Bot
- Built-in analytics dashboard
- Conversation transcripts
- Escalation to human agents
- Iterative improvement loop

### Ch 8: Copilot Studio + Power Automate – Working Together
- The orchestration pattern
- Passing variables between copilot and flows
- Real examples of the combo in action

### Ch 9: Real-World SMB Use Cases (Webinar Prep)
- Pulling together all concepts
- 5 concrete SMB scenarios
- How to present this to a non-technical audience
