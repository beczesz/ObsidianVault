## Megnyitás

- **Böngészőben:** nyisd meg az adott mappa `index.html` fájlját.
- Minden mappában van egy `PRODUCT.md` is — ez írja le a brandet, a döntéseket és a
  kerülendő kliséket (ezt használja az `/impeccable` a tervezéshez).

## A közös tanulság (miért lettek szépek)

1. **A kategória-reflex elkerülése** (pl. ügyvéd ≠ kék+arany, oktatás ≠ gyerek-clay).
2. **Hiteles tartalom** (valódi vagy meggyőzően kitalált), nem üres sablon.
3. **Egy bátor irány-döntés** (tipográfia vagy layout).
4. **Fegyelmezett szín + erős képek** (egy akcent / egységes duotón).
