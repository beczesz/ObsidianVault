Nem egy AI gondolkodik. Egy csapat. Egy karmesterrel.

Claude összehangol több AI-t (Opus, GPT‑5, Perplexity, Copilot), párhuzamosan kérdezi őket, majd egyetlen koherens szintézist ad vissza. A motor lényege nem a modellek száma, hanem hogy hol él az emlékezet.

A megalapozó belátás

A state file a tartós agy. Az AI‑ok csak cserélhető gondolkodási felületek.

Ha ezt elfogadod, eltűnik a „melyik AI a jobb" kérdés. Mindegyik modell ugyanazt csinálja: gondolkodik egy darabot. A durva kontextus a state file-ban él, nem a chat-ablakban.

Ezért nem baj, hogy az API hívás „állapot nélküli": minden körben a state file-ból injektáljuk a kontextust. A böngésző-AI „emlékezete" pedig csapda, amíg vissza nem szinkronizáljuk: különben rejtett, párhuzamos tudásbázist épít, amit egy másik AI se lát.

Az orkesztráció

A karmester párhuzamosan vezényel

A kör a felhasználóval indul: te brief-eled Claude-ot, ő szétosztja a feladatot minden tagnak (köztük egy második Claude-szálnak). Az API-tagok ~7 mp alatt válaszolnak, a böngésző-tag ~30 mp alatt, párhuzamosan. A végén Claude visszaad neked, mert a döntés a tiéd. A kör hossza a leglassabb tag ideje, nem az összeg. # Várakozás az első körre… ▌

A gondolkodási hurok

Nyolc lépés, minden körben ugyanaz

A transport (API vagy böngésző) változik, a hurok nem. Kattints egy lépésre.

Transport-pragmatizmus

Alapból API. Böngésző csak akkor, ha tud valamit, amit az API nem.

ALAPÉRTELMEZETT

API

Közvetlen curl-hívás. Gyors, strukturált, megbízható. Állapot nélküli, ezért a kontextust minden körben a state file-ból injektáljuk. Ez nem hátrány: így nincs rejtett, követhetetlen memória.

Egy kör Opus 4.7-tel: ~7 mp
Böngésző-körrel: ~30 mp

A böngésző (Chrome MCP) pontosan négy esetben nyer:

Hangmód

Account-oldali adat

Élő emberi beszélgetés

A felhasználó éppen chatel az AI-jal, és ki akarja nyerni azt a beszélgetést.

A memória-illúzió

„Az AI ismer engem"

Ha mindig ugyanabban a ChatGPT böngésző-szálban gondolkodsz, elkezded érezni, hogy „ismer". Pedig csak azt az egy ablakot ismeri. Nyiss új chatet, vagy válts API-ra, és a tudás elpárolog. A state file az, ami ismer téged. A böngésző-emlékezet csak cache, amit minden kör végén vissza kell szinkronizálni, különben drift-et okoz.

Csapat-összeállítás

A felhasználó állítja össze a gondolkodó csapatot

Minden tag kap szerepet és transportot. Válassz egy presetet, és nézd, hogyan áll össze.

A vezérelv

Állíts csapatot bölcsen. Válassz transportot pragmatikusan. Vezényelj proaktívan. Ments el mindent. Eszkalálj okosan. Hajts végre könyörtelenül: párhuzamosan, strukturált válaszokkal, API-n és böngészőn át.
